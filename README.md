# Igbalode Alhaja Trade Fair 1.0 | Attendee Card Maker
 
A lightweight web tool that lets event attendees create their own **"I will be attending"** card. They upload a photo, add their name and role, and download a branded image ready to share on social media.
 
Built for the **Igbalode Alhaja Trade Fair 1.0** (Liberty Stadium, Ring Road, Ibadan, 19th & 20th December 2026).
 
**Live demo:** [Link](https://igbalodealhaja.netlify.app/)

## Features
 
- Photo upload, with drag-to-position and zoom (slider, mouse wheel or pinch on mobile)
- Name and role fields, with text that shrinks automatically so long names always fit
- Live preview, so what visitors see is exactly what they download
- One-click download as a full-size **1080 × 1350 PNG**
- Fully client-side: no backend, no database, no storage costs, and photos never leave the visitor's device
- Responsive layout with automatic light and dark mode
